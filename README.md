| 写法  | 常见含义               | 示例                   |
| --- | ------------------ | -------------------- |
| `T` | Type，类型            | `T`                  |
| `K` | Key，键              | `K extends keyof T`  |
| `V` | Value，值            | `Map<K, V>`          |
| `U` | 第二个 Type           | `Promise<T \| U>`    |
| `P` | Props / Parameters | `Component<P>`       |
| `R` | Return / Result    | `Promise<R>`         |
| `E` | Element / Error    | `Array<E>`           |
| `S` | State / Source     | `State<S>`           |
| `A` | Argument           | `Function<A>`        |
| `C` | Context            | `Context<C>`         |
| `F` | Function           | `F extends Function` |
| `D` | Data               | `Response<D>`        |
